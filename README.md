## 專案結構

- `index.html`：首頁
- `matcha.html`：抹茶紅豆吐司頁面
- `style.css`：主要網頁樣式
- `matcha_style.css`：抹茶紅豆吐司頁面樣式
- `script.js`：JavaScript互動功能
- `images/`：網站使用的圖片素材

## 學習目的
